  # HanzuVPN Mini App

نسخه اولیه رابط Mini App آبی و شیشه‌ای HanzuVPN.

## فایل‌ها
- `index.html` صفحه اصلی و Loading
- `style.css` طراحی شیشه‌ای و تم آبی
- `app.js` رفتار رابط و Telegram Web App API
- `logo.png` لوگوی Hanzu

## انتشار روی Cloudflare Pages
این پوشه را به عنوان پروژه استاتیک منتشر کن. `index.html` باید در ریشه پروژه باشد.

## اتصال به ربات
نسخه فعلی رابط کاربری آماده است، اما برای اطلاعات واقعی کیف پول، سرویس‌ها و خرید باید یک endpoint/API امن به ربات یا بک‌اند متصل شود. `Telegram.WebApp.sendData` برای ارسال درخواست‌های اولیه از Mini App به ربات در نظر گرفته شده است.
